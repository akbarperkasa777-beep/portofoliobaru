# Folder gambar portfolio

Foto pada portfolio menggunakan dua file terpisah:

- `profile.jpg` untuk foto profil di bagian Hero.
- `about.jpg` untuk foto pada bagian Tentang Saya.

Ganti file yang sesuai untuk memperbarui masing-masing bagian.

Screenshot proyek disimpan di `projects/`. Lihat `projects/README.md` untuk
nama file dan daftar folder screenshot yang diperlukan.

Sertifikat lokal bisa disimpan di `certificates/`. Tambahkan path gambar,
judul, dan penyelenggara pada array `CERTIFICATES` di `script.js`.
