# Project screenshots

Use these filenames for project screenshots (or update the matching
`screenshots` paths in `script.js`). The Mini Kasir images are already populated
with the screenshots provided. Until another image is added, the portfolio
displays a clean "Screenshot belum tersedia" placeholder instead of a broken
image.

- `kasir/cover.jpg`, `screenshot-1.jpg`, `screenshot-2.jpg`
- `absen-karyawan/cover.jpg`, `screenshot-1.jpg`, `screenshot-2.jpg`
- `parkir/cover.jpg`, `screenshot-1.jpg`, `screenshot-2.jpg`

Add projects and change descriptions, technologies, GitHub repositories, and
live demo URLs in the `PROJECTS` array in `script.js`. Leave link values empty
until those URLs are available.
